# 🍕 foodie-delight-ecommerce

A modern, responsive e-commerce web application designed for restaurants, pizza outlets, and fast-food delivery services.

## ✨ Features
- 📱 **Fully Responsive Layout** (Mobile, Tablet, Desktop)
- 🍕 **Interactive Food Menus & Combos** (Pizzas, Burgers, Offers)
- 🛵 **Delivery & Order Call-to-Actions**
- 🌟 **Dynamic Carousel & Sliders** using Owl Carousel
- 🎨 **Clean & Vibrant UI** built with Bootstrap 5 and Custom CSS

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Styling & Frameworks:** Bootstrap 5, Font Awesome Icons
- **Plugins:** Owl Carousel 2
